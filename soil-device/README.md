# soil-device

Building a device that reads soil and suggests which crops suit it, learning electronics and IoT along the way. Build first, then ask why.

**Plan:** [Soil-to-Crop Device: Learning Roadmap](https://claude.ai/artifact/RaAsKcaeMt49wV2VtVsXHy) (14 weeks, Nov 2026 to Feb 2027, about 7 hours a week)

## How each week works

1. Build the week's mission (Wokwi simulator for weeks 1–2, real parts from week 3).
2. Run the experiments, then research the why-questions the build raised.
3. Write it up in that week's `README.md`: what I built, what broke, my why-answers.
4. Commit the code, the Wokwi `diagram.json`, and the notes.

## Layout

| Folder | What's in it |
| --- | --- |
| `week-XX-*/` | One folder per week: `sketch.ino`, `diagram.json`, `README.md` (notes) |
| `model/` | The crop-recommendation model, one notebook per week |
| `data/` | Datasets (not committed, see `data/README.md`) |
| `docs/` | Shopping list and reference notes |
